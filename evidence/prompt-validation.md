# 0.2.1 可编辑提示词验收

目标 DSH 0.2.1-rc.3，隔离 profile `spokesperson-report`，端口 31950。没有真实模型 API 调用，没有修改日常安装目录或 profile。

## 实现

新增原生 volatile 字段 `draftPrompt`、`reviewPrompt`，默认内容为此前完整的阶段提示词。用户设置直接替换全文，包含此前共用的职责与事实约束，末尾仅追加单独可编辑的“表达偏好”。用户文本不作模板插值，不 trim 有效正文，不设额外低长度上限；纯空白配置被拒绝。提示词仍随每个 attempt 的配置快照固定，并通过每步 system 记录实际发送内容。

前端入口：插件详情 → 模型与表达 → 提示词设置。两份多行文本框预填全文，分别提供恢复默认按钮。修改和恢复都先进入草稿，只有保存才通过原生 ConfigForm 原子写入当前 profile，并保留既有 revision 冲突保护。页面说明起草和核对的数据字段及表达偏好的附加方式。

## 边界

mock 证明配置、请求及持久化行为，不能证明真实模型一定遵守用户编写的提示词。编辑提示词不会改变 B 无工具权限或第一步排除 A 本次成稿的输入流程。旧历史不会重新调用模型。
